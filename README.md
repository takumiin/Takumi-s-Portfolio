# Takumi's Portfolio

就職活動用のポートフォリオサイトです。HTML / CSS / JavaScript のみで構成しており、ビルド不要で動作します。

## ローカルで確認する

`index.html` をブラウザで開くだけで表示できます。

## 編集方法

- 文章はすべて `index.html` に直接書かれています。
- `class="todo"` が付いている箇所は **要記入** です（画面上で黄色の破線枠で表示）。
  内容を書き換えたら `todo` クラスを外してください。
- 右下の「要記入を隠す」ボタンで、公開時の見え方を確認できます。
  `todo` がすべて無くなるとボタンは自動で消えます。

## 公開方法（GitHub Pages）

1. GitHub のリポジトリ画面で **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」にし、公開したいブランチと `/ (root)` を選んで Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます
